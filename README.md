# ✈️ Sky Flights Project

Проект представляет собой систему мониторинга авиационной активности над территорией выбранных стран. Программа связывает данные географических координат стран с информацией о воздушных судах, сохраняет их в реляционную базу данных и предоставляет встроенные инструменты для аналитики.

## 🛠️ Технологический стек
* **Язык программирования:** Python 3
* **База данных:** PostgreSQL
* **Драйвер БД:** psycopg2-binary
* **Работа с API:** requests

## 📋 Функционал и интеграции
1. **Интеграция с API:**
   * **Nominatim API (OpenStreetMap):** Используется для автоматического поиска географических границ стран (`boundingbox`) по их текстовому названию.
   * **OpenSky Network API:** Спроектирован для получения списка воздушных судов в режиме реального времени на основе переданных координат.
2. **База данных:**
   * Реализована реляционная схема данных из двух связанных таблиц: `countries` (страны) и `aeroplanes` (самолёты) с каскадным удалением (`ON COMPONENT / CASCADE`).
3. **Аналитический класс `DBManager`:**
   * `get_companies_and_aeroplanes_count()` — подсчёт количества самолётов по каждой стране.
   * `get_all_aeroplanes()` — вывод всех самолётов с привязкой к названию страны.
   * `get_avg_velocity()` — расчет средней скорости всех судов в базе.
   * `get_high_velocity_aeroplanes()` — фильтрация самолётов, летящих быстрее средней скорости.
   * `get_aeroplanes_by_keyword(keyword)` — поиск самолётов по фрагменту позывного (регистронезависимый поиск).

## 🚀 Как запустить проект

1. **Клонируйте проект и установите зависимости:**
   ```bash
   pip install psycopg2-binary requests
   ```
2. **Настройте подключение к PostgreSQL:**
   Откройте файл `main.py` и заполните словарь `DB_CONFIG` вашими актуальными данными (host, port, database, user, password).
3. **Запустите программу:**
   ```bash
   python main.py
   ```

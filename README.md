# ✈️ Sky Flights Project

Проект представляет собой модульную систему мониторинга авиационной активности над территорией выбранных стран. Программа связывает реальные географические данные стран с информацией о воздушных судах в воздухе, сохраняет их в реляционную базу данных PostgreSQL и предоставляет инструменты для глубокой аналитики.

## 🛠️ Технологический стек
* **Язык программирования:** Python 3
* **База данных:** PostgreSQL
* **Драйвер БД:** psycopg2-binary (в основной группе зависимостей)
* **Управление проектом:** Poetry
* **Тестирование:** pytest, pytest-cov

## 📂 Модульная структура проекта (SOLID)
Программа строго разделена на логические компоненты в соответствии с принципами объектно-ориентированного проектирования:
* **`config.py`** — централизованный модуль конфигурации (настройки БД, глобальные HEADERS, список из 10 целевых стран).
* **`db_init.py`** — модуль автоматической инициализации структуры базы данных. Создает таблицы `countries` и `aeroplanes` с каскадным удалением при первом запуске.
* **`api_clients.py`** — изолированный клиент для работы с внешними API. Реализует поиск границ через Nominatim API и сбор параметров воздушных судов через OpenSky Network API.
* **`db_manager.py`** — аналитический класс `DBManager`, инкапсулирующий в себе все регламентированные ТЗ методы работы с выборками на чистом SQL.
* **`main.py`** — точка входа в приложение, координирующая последовательный запуск всех этапов системы.
* **`test_db_manager.py`** — модуль юнит-тестирования аналитики с применением фикстур и механизмов изолирования `monkeypatch`.

## 🚀 Как запустить проект

1. **Установите зависимости проекта через Poetry:**
   ```bash
   poetry install
   ```
2. **Настройте подключение к вашей PostgreSQL:**
   Откройте файл `config.py` и заполните словарь `DB_CONFIG` вашими актуальными локальными данными.
3. **Запустите программу:**
   ```bash
   poetry run python main.py
   ```

## 📊 Тестирование и покрытие (Coverage)
* **Покрытие тестами:** 100% (класс `DBManager` полностью покрыт изолированными юнит-тестами).
* **Сборка отчёта:** Чтобы сгенерировать интерактивный HTML-отчёт локально, выполните:
  ```bash
  poetry run pytest --cov=db_manager --cov-report=html
  ```
  Результат будет доступен в папке `htmlcov/index.html`.
